# Spam Email Classifier

## Overview

The Spam Email Classifier is a simple Machine Learning project that classifies messages as **Spam** or **Not Spam (Ham)**. The model is trained using labeled message data and can predict the category of new messages.

## Features

* Detects spam and non-spam messages
* Text preprocessing and feature extraction
* Machine Learning-based prediction
* Easy to train and test with new messages

## Technologies Used

* Python
* Pandas
* Scikit-learn

## Machine Learning Algorithm

* Naive Bayes Classifier

## Project Workflow

1. Collect labeled message data.
2. Preprocess and clean the text.
3. Convert text into numerical features.
4. Train the Naive Bayes model.
5. Test the model on new messages.
6. Generate spam or non-spam predictions.

## Example

Input:
"Congratulations! You have won a free gift."

Output:
Spam

Input:
"Please attend the meeting at 5 PM."

Output:
Not Spam

## Learning Outcomes

* Understanding Machine Learning basics
* Data preprocessing techniques
* Model training and testing
* Prediction and accuracy evaluation
